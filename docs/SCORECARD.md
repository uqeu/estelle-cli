## Publication gate — v0.2.10 PUBLIC BYTES PASS

The two public-distribution rows above read back all six required facts from public systems:

1. the remote tag resolves to the intended source commit;
2. four release archives and `SHA256SUMS` exist at customer URLs;
3. the downloaded archive hashes to its manifest row and contains exactly one regular binary;
4. that binary prints the tag version;
5. the workflow produces GitHub OIDC provenance and an independent verifier confirms it;
6. `npm view --prefer-online @fatelabs/estelle` reports the native compatibility shim, and `npm pack`
   shows no abandoned JavaScript implementation inside it.

and a once-only real-repository file-shift warning after an actual disposable-file edit.

initialize, so fact 5 remains a read-back gap. Public installer execution, bare-command resolution, and the
real first-run picker succeeded; the stronger default-shell restart and founder-machine proof remain outside
this probe.
