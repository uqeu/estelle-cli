# context-checkpoint

Estelle's context-discipline move. Compact on purpose at natural seams, not blindly when the window fills — so nothing load-bearing is ever lost.

## Procedure
1. **Checkpoint at boundaries** — trigger at phase seams (design done, feature landed, tests green), not mid-thought and not on arbitrary auto-compaction.
2. **Summarize the phase** — capture what was decided and built in a few tight lines that stand on their own.
3. **Pin the essentials** — carry forward the facts, decisions, constraints, and file/API references the next phase actually needs.
4. **Drop the noise** — discard superseded attempts, dead ends, and verbose tool output that no longer informs anything.
5. **Verify before dropping** — confirm every pinned fact is preserved before releasing the raw context, so compaction never loses signal.
6. **Continue sharp** — resume the next phase on the lean summary, with headroom restored.

## Output
A compact, phase-aware context that keeps every load-bearing fact and sheds the rest. Serves long sessions; pairs with `baton-pass` for cross-agent handoff.
